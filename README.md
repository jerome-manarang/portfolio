## **How the Portfolio is Structured**
The **entry point** of this application is **`App.js`**, which manages the following three main components:

### **StickyHeader**
- Ensures that the **header remains visible** at the top of the page while scrolling.  

### **Main**
- Displays the **title section** with my name.  
- Animates the **clouds**, which represent my tech knowledge.

### **Projects**
- Contains **interactive clouds**, each linking to a **repository** for its respective project.
